## 2. Nội dung công việc đã thực hiện

### 2.1. Tìm hiểu và chuẩn bị

- Tìm hiểu yêu cầu của đồ án.
- Tìm hiểu tổng quan về CMS Joomla.
- Tìm hiểu cách vận hành và quản trị Website bằng Joomla.
- Chuẩn bị môi trường máy chủ Web cục bộ bằng XAMPP.
- Chuẩn bị cơ sở dữ liệu phục vụ Website.

### 2.2. Cài đặt Joomla

- Cài đặt Joomla trên máy chủ Web cục bộ.
- Thiết lập cơ sở dữ liệu cho Website.
- Kiểm tra Website sau khi cài đặt.
- Đăng nhập và làm quen với trang quản trị Joomla.

### 2.3. Xây dựng cấu trúc Website

- Xây dựng cấu trúc Website giới thiệu việc làm.
- Tạo các chuyên mục nội dung.
- Xây dựng menu điều hướng Website.
- Tổ chức nội dung theo từng nhóm thông tin.

Các nhóm nội dung chính gồm:

- Giới thiệu
- Việc làm
- Tin tức
- Nhà tuyển dụng
- Người tìm việc
- Thông báo
- Liên hệ

### 2.4. Xây dựng nội dung và giao diện

- Tạo và cập nhật các bài viết giới thiệu Trung tâm.
- Xây dựng nội dung thông tin việc làm.
- Xây dựng nội dung thông tin nhà tuyển dụng.
- Xây dựng nội dung thông báo.
- Xây dựng nội dung liên hệ.
- Điều chỉnh giao diện trang chủ.
- Cấu hình các module cần thiết.
- Cấu hình chức năng tìm kiếm.
- Kiểm tra cách hiển thị nội dung trên Website.

### 2.5. Quản lý dự án bằng GitHub

- Tạo GitHub Repository cho đồ án.
- Tạo file `README.md`.
- Cập nhật thông tin đề tài và nội dung thực hiện trong README.
- Tạo thư mục `progress-report` để lưu báo cáo tiến độ hàng tuần.
- Thực hiện commit các nội dung đã hoàn thành.

- Xây dựng được cấu trúc cơ bản của Website.
- Xây dựng được các menu và chuyên mục chính.
- Tạo được nội dung về việc làm, nhà tuyển dụng, tin tức, thông báo và liên hệ.
- Thiết lập được giao diện và các module cơ bản.
- Cấu hình được chức năng tìm kiếm.
- Tạo GitHub Repository để quản lý dự án.
- Bắt đầu sử dụng GitHub để lưu trữ tài liệu và theo dõi tiến độ.
